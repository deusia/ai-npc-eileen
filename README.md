# 归潮之灯：艾琳 AI NPC 原型

本地演示；每个会话独立保存对话、记忆和旅店世界。Python 标准库实现 Agent 循环，LM Studio 提供模型推理，SQLite 保存对话、模型提取的记忆、报价和游戏事件；无需安装第三方依赖。

## 运行

1. 在 LM Studio 的 Developer 页面启动本地服务器并加载目标千问模型。默认地址是 `http://127.0.0.1:1234/v1`。模型的实际标识以 LM Studio 为准；聊天和工具调用能力取决于具体模型及模板。
2. 在终端运行：

   ```bash
   cd ai-npc-eileen
   python3 app.py
   ```

3. 打开 http://127.0.0.1:8765 ，点击“新建会话”开始独立的旅店故事，或在“当前会话”中切换。新建会话从雨夜与一盏旧灯开始，玩家的话会以灯附近的声音传到艾琳的世界。此前的会话保留原设定与记录。与艾琳对话。例如询问三晚住宿价格，报价出现后可点击确认。

优先选择 `qwen3.8-27b-mlx`；否则只有一个模型时自动选择，若返回多个模型，请在启动前指定 `LM_STUDIO_MODEL='实际模型标识' python3 app.py`。可用 `LM_STUDIO_URL` 指定兼容 API 的地址。如果 LM Studio 开启了认证，程序从 `~/.config/ai-npc-eileen/token` 读取令牌；该文件应仅允许当前用户读取（权限 600）。也可用 `LM_API_TOKEN` 环境变量覆盖文件。不要把令牌写入源码或提交版本库。也可以同时设置 `LM_STUDIO_MODEL` 指定 `qwen3.8-27b-mlx`。LM Studio 支持 [Chat Completions 和工具调用](https://lmstudio.ai/docs/developer/openai-compat/tools)。

页面会流式显示回复；模型有返回推理内容时，可展开默认折叠的“思考过程”。成功完成的回复和推理会保存在各自会话中；出错或中断时应刷新确认结果后重试。

## 行为和限制

艾琳按角色设定、近期 20 条消息、近期及相关记忆、最近 10 条游戏事件及实时状态决策。模型可保存记忆、提出住宿报价；服务端校验 1–7 天、最多 10% 折扣、空房和余额。只有玩家点击确认才会扣款及减少空房，确认不可重复。所有报价、房间和金币均为演示规则，并非原聊天中已确定的游戏设定。

SQLite 默认保存在本目录的 `npc.db`，重启后保留。备份或删除该文件可以保留或重置整个单玩家世界；删除前请确认不再需要记录。服务仅监听本机，不提供账号、多用户权限隔离或公网安全机制。记忆由模型自主提取，不保证完整或准确；通过简单词语匹配召回旧记录，不提供语义检索。空房不会随时间恢复；尚未实现游戏引擎、语音、寻路和任务系统。模型可能输出与实际状态不符的文字，界面显示的状态和确认结果才是实际执行结果。

运行测试：`python3 -m unittest -v`。

新故事中的旧灯位置、通信次数和艾琳通过工具观察或移动产生的事件按会话保存在本地。新故事会话的时间从第一次成功交流开始，按现实经过时间一比一推进；旧会话在升级后第一次成功交流时开始计时，不推测之前的时间间隔。页面在刷新、切换会话或互动时更新时刻。系统按世界时间计算艾琳当下的简单日常状态；未逐分钟模拟她离线时的行动，也不会自主发起聊天。天气目前固定有雨。模型仍可能描写未执行的动作或将猜测说成事实，需继续评估。

新故事记忆可以标为来者自述、艾琳记录的经历或她的猜测；这些标记只是角色的记录，并非事实校验。模型可以修订记忆，修订前内容与原因会保留在本地。当前世界状态和已执行事件仍是世界事实的依据。

旧灯可以被仔细调查，发现的细节只有在观察成功后才会进入该会话的已知世界；细节本身不自动决定艾琳的解释。

服务运行时，后台会检查一次有触发条件的环境事件，并让艾琳基于可观察信息决定是否采取一个受限行动；也可在重逢时补算事件。尚未调查的内容不会传给模型，角色的猜测不等于世界事实。后台判断失败会有限次重试；推理期间如果玩家继续互动，过期决定会被丢弃。后台可能短暂占用本地模型资源，服务关闭后不运行。

新故事中，艾琳可以为少量已支持的世界行动记录具体打算，随后自己选择继续或放弃。只有对应工具实际成功执行并产生世界事件，打算才会标记完成；模型口头承诺不会直接改变状态。打算按会话隔离并持久保存，目前没有按时间自动执行的通用任务系统。

## 使用 GPT-6 Luna

网页的“对话模型”可选本地 LM Studio 或云端 GPT-6 Luna，默认仍为本地。选云端后，当前会话的近期对话、角色设定、相关记忆、世界状态及工具结果将发送至 OpenAI，使用 API 会产生费用；后台自主事件仍使用本地模型。

云端使用 OpenAI Responses API，设置 `store=false`；思考区展示 API 返回的推理摘要（如果有），不是完整内部推理。密钥从环境变量 `OPENAI_API_KEY` 或 `~/.config/ai-npc-eileen/openai-key` 读取，文件权限应为 600，环境变量优先。切换或轮换密钥后须重启服务。密钥不要写入源码、提交版本库或发送给其他人。

如需暂时关闭后台自主事件，可用 `NPC_STORY_WORKER=0 python3 app.py` 启动；对话功能不受影响。
